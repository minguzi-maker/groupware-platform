# 설치 가이드

groupware-platform 로컬 개발 환경을 준비하는 순서입니다.

## 1. Git 설치 (필수)

- 설치: https://git-scm.com/install/
- 참고: https://cafe.naver.com/f-e/cafes/28186338/articles/29528?boardtype=L&menuid=441&referrerAllArticles=false

참고 링크대로 Git을 설치합니다.
Git Bash에서 클론 받을 위치를 연 뒤 실행합니다.

```bash
git clone -b dev https://github.com/ibm05-team-3/groupware-platform.git
```

## 2. WSL + Docker Desktop 설치 (필수, 재시작 필요)

- 설치: https://docs.docker.com/desktop/setup/install/windows-install/
- 참고: https://cafe.naver.com/f-e/cafes/28186338/articles/31292?menuid=589&referrerAllArticles=false&page=2

1. 참고 링크대로 Docker Desktop을 설치합니다.
2. 필요하면 PC를 재시작합니다.
3. Docker Desktop을 실행하고 로그인합니다.
4. 터미널에서 `groupware-platform` 클론 폴더를 엽니다.
5. 인프라 컨테이너를 띄웁니다.

```powershell
docker compose up -d
```

## 3. DBeaver Community 설치 (대안 가능)

- 설치: https://dbeaver.io/
- 참고: https://cafe.naver.com/f-e/cafes/28186338/articles/22335?menuid=558&referrerAllArticles=false

1. 참고 링크대로 DBeaver를 설치합니다.
2. DBeaver를 실행합니다. Configure 설정은 모두 기본값으로 둡니다.
3. 새 데이터베이스 연결을 만듭니다.
4. PostgreSQL을 선택합니다.
5. PostgreSQL standard driver(맨 위)를 선택합니다.
6. Docker Desktop에서 `groupware-postgres`가 켜져 있는지 확인합니다.
7. Password에 `admin`을 입력합니다.
8. Database 항목 오른쪽의 **Show all databases**를 체크합니다.
9. **Test Connection**을 눌러 Connected가 나오면 완료합니다.
10. 클론 폴더의 `services\user-service\src\main\resources\db` \ `schema-dev.sql`을 DBeaver로 엽니다.
11. DBeaver의 Data Source를 `postgres`로 바꿉니다.
12. 아래 문장만 먼저 실행합니다.

```sql
CREATE DATABASE user_service ENCODING 'UTF8';
```

13. Schema를 `user_service`로 전환합니다.
14. `\c user_service;`를 제외한 아래쪽을 모두 실행합니다.

## 4. Eclipse Temurin JDK 21 설치 (대안 가능, Oracle JDK 가능)

- 설치: https://adoptium.net/temurin/releases/?version=21
- 참고: https://cafe.naver.com/f-e/cafes/28186338/articles/28297?boardtype=L&menuid=558&referrerAllArticles=false

1. 시작 메뉴에서 **환경 변수**를 검색하고 **시스템 환경 변수 편집**을 엽니다.
2. **환경 변수**를 클릭합니다.
3. 시스템 변수에서 새로 만듭니다.
   - 변수 이름: `JAVA_HOME`
   - 변수 값: 설치된 경로 (예: `C:\Program Files\Eclipse Adoptium\jdk-21.0.x.x-hotspot`)
4. `Path` 변수를 편집하고 `%JAVA_HOME%\bin`을 추가합니다.
5. 확인한 뒤 새 터미널에서 Java 버전을 확인합니다.

## 6. Node.js 설치 (필수)

- 설치: https://nodejs.org/en/download
- 참고: https://cafe.naver.com/f-e/cafes/28186338/articles/29630?menuid=464&referrerAllArticles=false

1. 참고 링크대로 설치합니다.

3. 의존성을 설치하고 개발 서버를 실행합니다.


5. 아래 계정으로 로그인합니다.

   - 비밀번호: `12341234`
6. 응답이 `200`이고 본문이 `{"authenticated":true,"userId":"1"}`이면 정상입니다.

## 10. Python 설치 (필수)

- 설치: https://www.python.org/downloads/release/python-31315/
- 참고: https://cafe.naver.com/f-e/cafes/28186338/articles/32432?menuid=598&referrerAllArticles=false
- 설치 버전: 3.13.15

1. 참고 링크대로 Python을 설치합니다. 설치 화면에서 **Add python.exe to PATH**를 체크합니다.
2. 새 터미널에서 `python --version`이 `Python 3.13.15`인지 확인합니다.
3. 클론 폴더의 `services\ai-service`로 이동합니다.
4. 가상환경을 만들고 의존성을 설치합니다.

```powershell
py -3.13 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -e .
```

`pyproject.toml`은 최소 버전만 지정합니다. 2026-11-16에 설치해 확인한 직접 의존성 버전은 아래와 같습니다.

| 패키지 | 버전 |
|--------|------|
| fastapi | 0.163.1 |
| uvicorn | 0.54.0 |
| pydantic-settings | 2.16.3 |
| langgraph | 1.2.22 |
| langchain | 1.5.0 |
| langchain-google-genai | 4.5.0 |
| mcp | 2.3.0 |

5. Gemini API 키를 발급합니다. 키 값은 문서와 Git에 적지 않습니다.

- 발급: https://aistudio.google.com/apikey
- Google 계정으로 로그인합니다.
- 처음이면 이용 약관에 동의합니다. AI Studio가 기본 프로젝트와 키를 만듭니다.
- 이미 Google Cloud 프로젝트가 있으면 Dashboard의 Projects에서 그 프로젝트를 가져온 뒤 키를 만듭니다.
- **Create API key**로 키를 만들고 복사합니다. 2026년 5월 28일 이후 새 키는 승인 키입니다.

6. `ai-service`를 띄울 PowerShell 창에만 키를 넣습니다. 그 창을 닫으면 값은 사라집니다.

```powershell
$env:GOOGLE_API_KEY = "발급받은 키"
.\.venv\Scripts\python.exe -m uvicorn app.main:app --port 8100
```

7. http://localhost:8100/health 에 접속합니다. 응답이 `{"status":"ok"}`이면 정상입니다.
